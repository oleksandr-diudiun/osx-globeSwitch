## Correct selected text and switch layouts in Apple Mail

One Globe press now corrects the selected text and switches between ABC and Ukrainian-PC in the Mail compose editor. GlobeSwitch uses the editor’s text markers to verify the replacement before it switches layouts. The user confirmed the behavior in Apple Mail.

This release also improves verification in editors that expose their contents and selected text but omit the selection position. When the selected text occurs exactly once, GlobeSwitch can verify the replacement using the full field value. If verification fails, diagnostics record the app, field role and available accessibility information without logging the text.

Download **GlobeSwitch-0.3.4-arm64.dmg** for Apple Silicon and drag GlobeSwitch into Applications. The release includes a SHA-256 checksum. All 19 automated tests passed.
